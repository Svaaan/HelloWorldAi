How a job runs

  1. 1

    You send a dataset

    A spreadsheet, and which column you want predicted. Part of it is held back before anything is sent out.

  2. 2

    An idle GPU trains it

    The job goes to a machine somebody offered. Its owner can approve each one, and it stops on its own if the card gets too hot.

  3. 3

    The result is checked

    The coordinator scores the returned model itself, on the rows that were held back — so the grade does not come from the machine being graded.
