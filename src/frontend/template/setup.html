Setup Guide for Node Contribution

⚠️ Warning: This setup may challenge your technical skills. It is part of exploring new and exciting ground. We’re building something innovative, and your contribution is key!

Why connect your GPU to the AI Network?

  • Earn passive income: You can generate revenue by renting out your GPU power.
  • No access to your system: HelloWorldAI never directly accesses your GPU. All tasks run locally on your machine using open-source code inside a Docker container, ensuring full control and transparency.
  • Use what you already have: Many people already have high-performance GPU(s) that are idle or underutilized. This is a way to put them to work, contributing to real AI workloads.

This project is about building an open, privacy-respecting, and decentralized infrastructure for AI. Every connected GPU strengthens the network — and everyone is welcome to contribute.

By participating, you help make powerful computing available to independent developers and researchers who otherwise couldn't afford centralized services. This opens up new opportunities for AI innovation, experimentation, and collaboration — without relying on large corporations.

1
Install NVIDIA GPU Driver

Install the latest NVIDIA GPU driver on Windows (do not install a Linux driver inside WSL).

→ Download NVIDIA Drivers
1.5
Run Auto Setup Script (does steps 3–6 for you)

This installs Docker and the NVIDIA Container Toolkit, checks that a container can actually see your GPUs, then fetches and starts the node. It is safe to re-run — every step checks before it acts.

Run it inside Ubuntu on WSL 2. If you do not have WSL 2 yet, do step 2 first, then come back here.

Loading…
Download setup-node.sh
2
Install WSL 2 (Windows Subsystem for Linux)

Install WSL 2 with Ubuntu to run Linux tools on Windows without needing a USB or dual boot.

→ WSL2 Installation Guide
3
Install Docker and Toolkit in Ubuntu (inside WSL)

Launch Ubuntu from Start Menu and run the following:

curl -fsSL https://get.docker.com | sh sudo apt install -y wget sudo systemctl restart docker
4
Install CUDA Toolkit for WSL — not required

You can skip this. The node runs inside a container built on nvidia/cuda, which already carries the CUDA runtime. On the host you only need the driver (step 1), Docker and the NVIDIA Container Toolkit (step 3). Install the full toolkit below only if you want to build CUDA code yourself — it is several GB.

If you do want it, run the following to install the CUDA 12.8 Toolkit for WSL:

wget https://developer.download.nvidia.com/compute/cuda/repos/wsl-ubuntu/x86_64/cuda-wsl-ubuntu.pin sudo mv cuda-wsl-ubuntu.pin /etc/apt/preferences.d/cuda-repository-pin-600 wget https://developer.download.nvidia.com/compute/cuda/12.8.1/local_installers/cuda-repo-wsl-ubuntu-12-8-local_12.8.1-1_amd64.deb sudo dpkg -i cuda-repo-wsl-ubuntu-12-8-local_12.8.1-1_amd64.deb sudo cp /var/cuda-repo-wsl-ubuntu-12-8-local/cuda-*-keyring.gpg /usr/share/keyrings/ sudo apt-get update sudo apt-get install -y cuda-toolkit-12-8
5
(Optional) Add CUDA Compiler (nvcc)

If you want to compile CUDA programs, install the compiler separately:

sudo apt-get install -y cuda-compiler-12-8
6
Verify GPU Detection

Check that your GPU is detected correctly:

docker run --rm --gpus all nvidia/cuda:12.2.0-base-ubuntu22.04 nvidia-smi
7
Connect to the AI Network

You’re now ready to contribute your GPU to decentralized AI computing.
